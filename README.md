# brain

Config, rules, scripts, hooks, plugins and the installer for the company's knowledge work.
The knowledge base is a separate repo, `DataWithDaru/wiki`, cloned next to this one as
`wiki/`. Its notes, its `index.md` and its own `CLAUDE.md` live there.

The rules are in [`_ai/rules.md`](_ai/rules.md). To set up a machine, read
[`_ai/update.md`](_ai/update.md), or run `python scripts/install_vault.py --wiki ../wiki`
after cloning both repos side by side.
